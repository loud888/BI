Hệ thống Business Intelligence giúp phân tích kết quả học tập của sinh viên, hỗ trợ nhà trường đưa ra quyết định dựa trên dữ liệu.

- Thiết kế Data Warehouse theo Star Schema
- Xây dựng quy trình ETL
- Phân tích insight và trực quan hóa dữ liệu

- **Database**: PostgreSQL
- **ETL**: Python (pandas, SQLAlchemy)
- **Dashboard**: HTML + Chart.js / Excel PivotTable
- **IDE**: DBeaver, VS Code
